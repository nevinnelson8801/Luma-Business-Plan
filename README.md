# LUMA — The Complete Business Plan

**Design-led illuminated signage and media company, starting in Trivandrum, Kerala.**

A four-phase plan to grow from a ₹3–5L lightbox workshop into a company
delivering mega-LED and naked-eye 3D installations (₹2–4Cr projects).

## Live plan

Open [`index.html`](index.html) in any browser. It is a single self-contained
file (images embedded), so it works offline. Fonts load from Google Fonts when online.

To host it free: **Settings → Pages → Deploy from branch → `main` / root**.

## The four phases

| Phase | Focus | Start cost | Monthly revenue target |
|-------|-------|-----------|------------------------|
| 1 | Lightbox advertising (PVC, aluminium, rotating cubes) | ₹3–5L | ₹1.5–2L |
| 2 | Showroom and premium products | ₹8–15L | ₹5–8L |
| 3 | LED advertising panels | ₹60–80L | ₹8–20L |
| 4 | Mega LED and 3D installations (2029+) | ₹2–4Cr | ₹20–40L |

Each phase keeps earning while the next one starts: one business, getting brighter.
